## 🏆 Projects

### [Passify-Pro](https://github.com/freemarketamilitia/passify-pro)  
A WooCommerce plugin that auto-generates Google Wallet passes for ticket sales. Built with PHP, JS, and Google Wallet API.

### Roller Rink Snack Bar Ordering  
Custom mobile ordering system for timed pickup at Grand Terrace Roller Rink. Real-time status, admin dashboard, PHP/JS.

### Keyword Kraken  
AI-Driven Keyword Planner: competitor analysis, trend detection, SERP intent, clustering, and exportable SEO reports—powered by Python & JS.

### Mystery Basket Showdown  
Cross-classroom quiz game using Google Apps Script & Classroom API. Features templating, teacher/student dashboards, team support.

### Google Classroom Autograder (Flask)  
Flask API that grades arbitrary Google Docs, Sheets, Forms. Integrates official Google Python client libs and automates email feedback.
